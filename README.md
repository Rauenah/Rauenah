# 👩🏻‍💻 Rhauenah

**`Analista de Dados Em Formação`**

Me chamo Rauenah, morando em São Paulo.  Pós‑Graduada em Ciências de Dados pela ESALQ/USP, onde desenvolvi uma base sólida em análise, visualização e interpretação de dados.
Atualmente, estou aprofundando meus conhecimentos em códigos, modelagem de dados e ferramentas de Business Intelligence, com foco especial em Power BI, SQL e Python.
Sou apaixonada por tecnologia, aprendizado contínuo e pela capacidade que os dados têm de transformar decisões. Busco sempre evoluir, criar projetos práticos e compartilhar conhecimento enquanto construo minha trajetória na área de dados.
